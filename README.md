# Pixora — AI-Powered Smart Photo Studio

Pixora is a private, local-first desktop photo studio. This repository currently delivers **Phase 1**: the professional PySide6 application foundation, navigation shell, dashboard, theme preference, and interaction-ready UI components.

## Run

```powershell
python -m pip install -r requirements.txt
python main.py
```

## Phase status

- [x] Phase 1 — polished desktop interface and architecture foundation
- [ ] Phase 2 — folder scanning and local image import
- [ ] Phase 3+ — gallery, computer vision analysis, enhancements, database, packaging

All future image processing will be designed to run locally and preserve originals.
